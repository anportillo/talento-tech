# talento-tech
Sitio web de primer entrega, contiene:

- Estructura semántica en HTML5 (`header`, `nav`, `main`, `section`, `footer`)
- Formulario de contacto funcional utilizando Formspree
- Estilos aplicados con CSS externo y Google Fonts
- Diseño responsivo utilizando Flexbox y Grid
- Inclusión de contenido multimedia
- Navegación interna mediante enlaces ancla
- Publicación del sitio en GitHub Pages
